# 마크다운 문법 가이드

마크다운은 일반 텍스트 문서에 서식 요소를 추가하는 데 사용할 수 있는 경량 마크업 언어이다.

### 1. 제목
제목을 만들려면 단어나 구 앞에 숫자 기호(`#`)를 추가한다. 숫자 기호의 수는 제목 수준에 해당한다.

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

### 2. 강조
*   **굵게:** 텍스트를 굵게 표시하려면 단어나 구 앞뒤에 별표 두 개(`**`) 또는 밑줄 두 개(`__`)를 추가한다.
    ```markdown
    **이 텍스트는 굵게 표시된다.**
    __이 텍스트도 굵게 표시된다.__
    ```
*   **기울임꼴:** 텍스트를 기울임꼴로 표시하려면 단어나 구 앞뒤에 별표 하나(`*`) 또는 밑줄 하나(`_`)를 추가한다.
    ```markdown
    *이 텍스트는 기울임꼴이다.*
    _이 텍스트도 기울임꼴이다._
    ```
*   **굵게 및 기울임꼴:** 별표 세 개(`***`) 또는 밑줄 세 개(`___`)를 조합한다.
    ```markdown
    ***이 텍스트는 굵고 기울임꼴이다.***
    ```

### 3. 목록
*   **순서 없는 목록:** 줄 항목 앞에 대시(`-`), 별표(`*`) 또는 더하기 기호(`+`)를 사용한다.
    ```markdown
    - 항목 1
    - 항목 2
      * 중첩 항목 A
      * 중첩 항목 B
    ```
*   **순서 있는 목록:** 숫자 뒤에 마침표(`.`)를 사용한다. 실제 숫자는 중요하지 않으며 마크다운이 순차적으로 렌더링한다.
    ```markdown
    1. 첫 번째 항목
    2. 두 번째 항목
       1. 중첩된 순서 있는 항목
       2. 다른 중첩 항목
    3. 세 번째 항목
    ```

### 4. 링크
*   **인라인 링크:** 링크 텍스트에는 대괄호를 사용하고 URL에는 괄호를 사용하며 선택적으로 따옴표 안에 제목을 추가할 수 있다.
    ```markdown
    [예제 링크](https://www.example.com "선택적 제목")
    ```
*   **참조 스타일 링크:** 링크에 대한 레이블을 정의한 다음 문서의 다른 곳에서 참조한다.
    ```markdown
    [예제 링크][id]

    [id]: https://www.example.com "선택적 제목"
    ```

### 5. 이미지
*   **인라인 이미지:** 링크와 유사하지만 느낌표(`!`)로 시작한다.
    ```markdown
    ![이미지에 대한 대체 텍스트](image.jpg "선택적 제목")
    ```
*   **참조 스타일 이미지:**
    ```markdown
    ![대체 텍스트][id]

    [id]: image.jpg "선택적 제목"
    ```

### 6. 인용문
인용하려는 텍스트 앞에 부등호 기호(`>`)를 사용한다.
```markdown
> 이것은 인용문이다.
> 여러 줄에 걸쳐있을 수 있다.
>
> > 중첩된 인용문.
```

### 7. 코드
*   **인라인 코드:** 코드를 단일 백틱(`` ` ``)으로 묶는다.
    ```markdown
    이것은 `인라인 코드`이다.
    ```
*   **코드 블록(펜스 코드 블록):** 코드 블록 앞뒤에 세 개의 백틱(``````)을 사용한다. 구문 강조를 위해 언어를 지정할 수 있다.
    ```markdown
    ```python
    print("안녕하세요, 월드!")
    ```
    ```

### 8. 수평선
수평선을 만들려면 한 줄에 하이픈 세 개(`---`), 별표 세 개(`***`) 또는 밑줄 세 개(`___`)를 사용한다.
```markdown
---
```
